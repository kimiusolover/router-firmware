# router-firmware

[English README](README.md)

対応ルーター向けの、再現可能なファームウェア構成・イメージ組立・成果物証明を扱います。上流ソース本体はここへ複製せず、固定された入力・パッチ・製品設定を組み合わせます。

## 重要な状態

`ax23v-v1` は探索段階です。パーティション、署名形式、SoC 対応、入力ソース、検証手順が一次資料で確立されるまで、フラッシュ可能なイメージは作成しません。テスト用の `ROUTER-FIRMWARE-UNFLASHABLE` 成果物は実機に書き込めません。

U-Boot、MAC アドレス、Wi-Fi 校正値、ART、メーカー予約領域を作成・置換・同梱しません。対象の不明点は推測せず、各工程は不足時に停止します。

## 貢献

パッケージレシピ、再現可能ビルド、テスト、文書、非破壊のハードウェア根拠確認を歓迎します。実機に影響する変更は、関連する根拠とレビューを添えてください。詳細は [POLICY.ja.md](POLICY.ja.md) を参照してください。
